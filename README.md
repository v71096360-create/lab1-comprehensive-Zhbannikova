Часть 2. Модуль формализации процесса ревьюирования (chapter2.bat)
Описание
Интерактивная система поиска дефектов в фрагментах кода. Пользователю показываются 5 фрагментов кода (релевантных FastAPI/Django/Flask) с намеренными ошибками. Нужно выбрать тип дефекта из предложенного списка. В конце выводится уровень ревьюера (Junior/Middle/Senior) на основе точности ответов.

echo 1: @app.get("/users/{user_id}")

echo 4:     return user

choice /c 123 /n
if errorlevel==2 (

    echo Неверно. Правильный ответ: 2

if errorlevel==1 (

Часть 3. Модуль сравнительного анализа альтернатив (chapter3.bat)
Описание
Интерактивная система сравнительного анализа трёх альтернатив методом взвешенной суммы (WSM). Пользователь назначает веса критериям (сумма = 100) и оценивает каждый фреймворк по шкале 1-5. Модуль автоматически рассчитывает взвешенные баллы и объявляет победителя.
Листинг кода
bat
@echo off
chcp 65001 >nul

echo ========================================
echo   Модуль сравнительного анализа (WSM)
echo ========================================
echo.
echo Назначьте веса критериям (сумма должна быть ровно 100):
set /p w1="1. Производительность и асинхронность (%%): "
set /p w2="2. Скорость разработки и встроенные функции (%%): "
set /p w3="3. Масштабируемость и экосистема (%%): "

set /a total_weight=w1+w2+w3
if %total_weight% neq 100 (
    echo.
    echo ОШИБКА: Сумма весов = %total_weight%, а должна быть 100.
    pause
    exit /b
)

echo.
echo Оцените альтернативы по шкале от 1 до 5:
echo.
echo --- FastAPI ---
set /p f1="Производительность (1-5): "
set /p f2="Скорость разработки (1-5): "
set /p f3="Масштабируемость (1-5): "

echo.
echo --- Django ---
set /p d1="Производительность (1-5): "
set /p d2="Скорость разработки (1-5): "
set /p d3="Масштабируемость (1-5): "

echo.
echo --- Flask ---
set /p fl1="Производительность (1-5): "
set /p fl2="Скорость разработки (1-5): "
set /p fl3="Масштабируемость (1-5): "

set /a score_f=f1*w1 + f2*w2 + f3*w3
set /a score_d=d1*w1 + d2*w2 + d3*w3
set /a score_fl=fl1*w1 + fl2*w2 + fl3*w3

echo.
echo ========================================
echo          МАТРИЦА РЕШЕНИЙ
echo ========================================
echo Критерий                     ^| Вес ^| FastAPI ^| Django ^| Flask
echo -----------------------------^|-----^|---------^|--------^|------
echo Производительность           ^| %w1%  ^|   %f1%    ^|   %d1%   ^|  %fl1%
echo Скорость разработки          ^| %w2%  ^|   %f2%    ^|   %d2%   ^|  %fl2%
echo Масштабируемость             ^| %w3%  ^|   %f3%    ^|   %d3%   ^|  %fl3%
echo -----------------------------^|-----^|---------^|--------^|------
echo ИТОГОВЫЙ БАЛЛ                ^|      ^|  %score_f% ^|  %score_d% ^|  %score_fl%
echo ========================================
echo.

set winner=FastAPI
set max_score=%score_f%

if %score_d% gtr %max_score% (
    set winner=Django
    set max_score=%score_d%
)
if %score_fl% gtr %max_score% (
    set winner=Flask
    set max_score=%score_fl%
)

echo ПОБЕДИТЕЛЬ: %winner% (набрал %max_score% баллов)
echo.
pause
Ключевые участки кода
set /p w1="..." — ввод весов с клавиатуры
if %total_weight% neq 100 — проверка суммы весов
set /a score_f=f1*w1 + f2*w2 + f3*w3 — формула взвешенной суммы S = Σ(W × X)
^| — экранированный символ для таблицы
if %score_d% gtr %max_score% — определение победителя

Часть 4. Интеграция модулей и финальная сборка (lab_system.bat)
Описание
Главный файл, который объединяет все три модуля в единую систему с меню выбора. Пользователь может запустить любой модуль отдельно или все три последовательно (пункт 4). После прохождения всех модулей выводится итоговый отчёт и результаты сохраняются в файл report.txt.
Листинг кода
bat
@echo off
chcp 65001 >nul

:menu
cls
echo ========================================
echo   СИСТЕМА МОДЕЛИРОВАНИЯ ПРОЦЕССОВ РАЗРАБОТКИ ПО
echo ========================================
echo.
echo 1. Модуль выбора технологий
echo 2. Модуль инспекции кода
echo 3. Модуль сравнительного анализа
echo 4. Запустить все модули последовательно
echo 5. Выход
echo.
set /p choice=Ваш выбор: 

if "%choice%"=="1" (
    call chapter1.bat
    goto menu
)
if "%choice%"=="2" (
    call chapter2.bat
    goto menu
)
if "%choice%"=="3" (
    call chapter3.bat
    goto menu
)
if "%choice%"=="4" (
    echo.
    echo Запуск всех модулей последовательно...
    echo.
    echo === МОДУЛЬ 1: Выбор технологий ===
    call chapter1.bat
    
    echo.
    echo === МОДУЛЬ 2: Инспекция кода ===
    call chapter2.bat
    
    echo.
    echo === МОДУЛЬ 3: Сравнительный анализ ===
    call chapter3.bat
    
    echo.
    echo ========================================
    echo   ИТОГОВЫЙ ОТЧЁТ СИСТЕМЫ
    echo ========================================
    echo.
    echo Модуль 1: Рекомендация по технологии сформирована.
    echo Модуль 2: Уровень ревьюера определён.
    echo Модуль 3: Победитель сравнительного анализа определён.
    echo.
    echo Результаты сохранены в report.txt
    echo.
    
    echo Итоговый отчёт системы > report.txt
    echo Дата: %date% %time% >> report.txt
    echo. >> report.txt
    echo Модуль 1: Рекомендация по технологии сформирована. >> report.txt
    echo Модуль 2: Уровень ревьюера определён. >> report.txt
    echo Модуль 3: Победитель сравнительного анализа определён. >> report.txt
    
    pause
    goto menu
)
if "%choice%"=="5" (
    echo.
    echo До свидания!
    pause
    exit
)

echo Неверный выбор. Попробуйте снова.
pause
goto menu
Ключевые участки кода
:menu — метка для возврата в главное меню
cls — очистка экрана
call chapterN.bat — запуск модулей
goto menu — возврат в меню после завершения модуля
> report.txt и >> report.txt — создание и дополнение файла отчёта
%date% %time% — автоматическая подстановка даты и времени
